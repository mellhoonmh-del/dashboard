# 📚 공부 습관 대시보드 (Study Habit Dashboard)

> **파이썬(Python)과 스트림릿(Streamlit)을 처음 접하는 비전공자 1학년 학생들을 위한 학습 프로젝트입니다.**

이 프로젝트는 `study.csv` 데이터를 읽어와 학생들의 공부 시간, 스마트폰 사용 시간, 그리고 시험 점수 간의 관계를 시각적으로 분석할 수 있는 웹 대시보드를 제공합니다.

---

## 📁 프로젝트 구조 (Directory Structure)

프로젝트 폴더 내에 아래 파일들이 같은 위치에 있어야 정상적으로 동작합니다.

```text
├── app.py             # 스트림릿 메인 웹 애플리케이션 코드
├── study.csv          # 학습 데이터 파일 (학생ID, 공부시간, 스마트폰, 점수)
├── requirements.txt   # 필요 파이썬 라이브러리 목록
└── README.md          # 프로젝트 설명 및 사용 설명서
```

---

## 🚀 빠른 시작 가이드 (Getting Started)

### 1. 필수 라이브러리 설치

터미널(Terminal) 또는 명령 프롬프트(CMD)를 열고, 프로젝트 폴더로 이동한 뒤 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 스트림릿 앱 실행

설치가 완료되면 다음 명령어로 대시보드를 실행합니다.

```bash
streamlit run app.py
```

명령어를 실행하면 웹 브라우저가 자동으로 열리며 대시보드가 표시됩니다. (기본 주소: `http://localhost:8501`)

---

## 💡 대시보드 주요 기능

1. **주요 지표 요약 (Key Metrics)**:
   - 총 학생 수, 평균 공부 시간, 평균 스마트폰 사용 시간, 평균 시험 점수를 한눈에 확인합니다.
2. **사이드바 필터링 (Sidebar Filter)**:
   - 공부 시간 슬라이더를 조절하여 원하는 조건의 학생 데이터만 실시간으로 필터링할 수 있습니다.
3. **인터랙티브 시각화 (Plotly Charts)**:
   - **공부 시간 vs 시험 점수**: 공부 시간이 점수에 미치는 영향을 확인합니다.
   - **스마트폰 사용 시간 vs 시험 점수**: 스마트폰 사용이 점수에 미치는 영향을 확인합니다.
   - 마우스를 그래프 위에 올리면 학생별 상세 정보를 확인할 수 있습니다.
4. **데이터 테이블 보기 (Data Table)**:
   - 접기/펴기(Expander) 기능을 통해 원본 데이터를 표 형태로 확인합니다.

## 📖 핵심 파이썬 개념 요약 (조교의 팁)

* **`pandas`**: CSV 파일을 읽어오고 데이터를 조건에 맞게 계산/필터링하는 라이브러리
* **`streamlit`**: 파이썬 코드 몇 줄로 손쉽게 웹 화면을 만들어주는 라이브러리
* **`plotly`**: 마우스 조작이 가능한 반응형 그래프를 그려주는 라이브러리
